# Crudos — las grabaciones originales

Dejá acá los videos tal cual salieron del celular o la cámara. Al arrancar un reel, el crudo se
mueve a `Crudos/<proyecto>/` y no se toca nunca más: todo lo que se edita se hace sobre copias
en `Ediciones/<proyecto>/`.

Para un reel de **reacción** son 3 crudos: el video al que reaccionás, vos reaccionando y vos
dando tu opinión.

Los videos no se suben a git.
