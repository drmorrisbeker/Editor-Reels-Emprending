# crudos/ — bandeja de entrada

Acá dejás los videos crudos antes de empezar a editar, ordenados por perfil.

- Reel de habla a cámara (yapping): `crudos/<perfil>/<archivo>.mp4`.
- Reel de reacción: `crudos/<perfil>/<carpeta>/` con `reaccion.mp4`, `camara.mp4` y `comentario.mp4` adentro.
- Al arrancar un proyecto, el crudo se **mueve** (no se copia) a `public/proyectos/<slug>/Crudos/`.
- Nada de esta carpeta se versiona en git: es material de trabajo local.
