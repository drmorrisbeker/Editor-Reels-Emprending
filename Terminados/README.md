# Terminados — los reels listos para publicar

Una carpeta por reel (`Terminados/<proyecto>/`) con:
- `<proyecto>.mp4` — el video final
- `caption.txt` — el texto para pegar en Instagram / TikTok / YouTube Shorts, optimizado para SEO
- `ganchos.txt` — portada, gancho y primeros 3 segundos (para analizar qué funcionó)

Nada de esto se sube a git.
